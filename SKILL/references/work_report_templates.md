Use this reference when turning work-management spreadsheet data into reusable report artifacts.

## 2. xlsx 欄位定義表

| 欄位 | 型別 | 必填 | 說明 | 範例 | 備註 |
| --- | --- | --- | --- | --- | --- |
| index | 整數 | 否 | 列序號 | 0 | 方便排序與追蹤 |
| 任務 | 文字 | 是 | 工作項目名稱 | 例行性任務 | 建議維持簡短可辨識 |
| 資訊需求單 | 文字 | 否 | 對應需求單或申請狀態 | 尚未申請 | 可填單號、狀態或簡述 |
| 優先順序 | 文字 | 否 | 任務優先等級 | 高 / 中 / 低 | 若有固定枚舉，請統一 |
| PEOPLE | 文字 | 否 | 負責人 | Carol | 可對應英文或中文姓名 |
| STATUS | 文字 | 是 | 任務狀態 | 進行中 | 建議固定成幾個狀態值 |
| 進度 | 數字 | 否 | 完成比例 | 0.9 | 建議範圍 0~1 |
| 開始日期 | 日期 | 否 | 任務起始日 | 2026-04-07 | 以 ISO 格式優先 |
| FinishDate | 日期時間 | 否 | 實際完成時間 | 2026-05-04 00:00:00 | 若未完成可留白 |
| 預計結束日期 | 日期時間 | 否 | 預計完成時間 | 2026-05-04 00:00:00 | 用於排程與預警 |
| 工時 | 數字 | 否 | 投入時數 | 8.5 | 可小數 |
| 說明 | 文字 | 否 | 補充說明 | 多筆工作內容摘要 | 可保留換行與明細 |

## 3. pptx 頁面大綱

1. 封面：報告名稱、期間、報告人、來源檔案。
2. 摘要頁：完成 / 進行中 / 待確認 / 風險四個區塊。
3. 任務總覽：依狀態、優先順序或負責人彙總。
4. 本週完成項目：列出關鍵任務與成果。
5. 進行中與阻塞項：列出卡點、依賴與需要協助事項。
6. 下一步：下週優先處理事項與預計完成時間。
7. 附錄：完整工作清單或資訊需求單明細。

## 4. 產出規則

- 先保留原始欄位名稱，再決定是否轉成更適合報告閱讀的標題。
- 若來源資料有明顯缺值，保留空白，不要自行補值。
- Markdown 偏向可複製與快速提交；xlsx 偏向結構化資料；pptx 偏向高層摘要。
- 若要轉成 skill 行為，優先讓 AI 直接套用這份模板，而不是重新發明格式。
